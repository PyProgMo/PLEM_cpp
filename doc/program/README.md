# Program Documentation Hub

This folder is the project-level documentation entry point for **fast, performance-critical measurements**.

## Goal
Integrate multiple measurement devices (spectrometer, CCD cameras, laser, powermeter, and additional hardware) through wrappers, while keeping this application focused on:

- unified control UI
- asynchronous operation
- fast measurement loops
- 1D/2D/3D display workflows

## Documentation Map
- `../md/PROGRAM_STRUCTURE.md` — complete program structure
- `../md/DEVICE_INTEGRATION.md` — how to add and wrap new devices
- `../md/MEASUREMENT_FLOW_AND_NEXT_STEPS.md` — init/measure/display wiring and roadmap
