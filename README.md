The scope of this Repository: 
Since https://github.com/PyProgMo/labview-plem was kind of a mess, This Project was build to reproduce the Frontend in C++ employing the fast, light toolkit (fltk). 
The Second scope was, to embed the devices then in seperate projects and connect them to the frontend. 

The Powermeter has been added so far. The https://github.com/PyProgMo/autostage_cpp Project is threfore to bundle all other relevant devices into one stack with a console app. 
If the console app is connected to all devices, it can be included here and the functions of the cli mapped to whatever button on the frontend fits.
